# Vision Jiu Jitsu — Prof. Ronaldo Reis

Projeto preparado em Next.js para publicação no GitHub e implantação na Vercel.

## Executar localmente

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Publicar na Vercel

Importe o repositório na Vercel e mantenha:

- Framework Preset: Next.js
- Build Command: `npm run build`
- Output Directory: deixe vazio
- Root Directory: `./`

Não configure `.next` ou `out` como Output Directory.
